# 深度拆书 · 小红书知识卡片工作台

把一篇有深度的文章、一本书的章节或你的读书笔记，变成一套 6–8 张、风格统一的小红书知识卡片。

它不做"全书摘要"，只做一件事：找出原文里**最反直觉的那个认知转折**，再把它拆成一张张卡。

## 它怎么工作

整个流程分三步，每一步结束都会停下来等你确认，不会一口气跑到底：

| 阶段 | 你会拿到什么 | 你要做什么 |
|---|---|---|
| 一 · 凝练稿 | 一句话核心命题 + 6–8 张卡的内容表（标题、正文、视觉隐喻、原文出处）+ 风格推荐 | 改内容、选风格 |
| 二 · 出图提示词 | 一段全套共用的风格总纲 + 每张卡单独的出图提示词 | 确认 |
| 三 · 生图 | 先出封面样张，确认后逐张生成，最后附小红书笔记正文 | 看样张、挑错字 |

内置 4 套适合拆书的风格：**杂志内页 / 手绘图解 / 观点大字 / 概念图谱**，AI 会根据内容推荐最合适的一套。

受众可选：家长学生、职场成人，或两边都要（应用卡会拆成"家长版"和"职场版"两张）。

## 怎么用

### 方式一：直接复制提示词（最简单，任何 AI 都能用）
1. 打开 [`prompt.md`](./prompt.md)，复制全文。
2. 把文章或章节粘贴到最后的「素材」位置。
3. 发给 ChatGPT（可直接调用 GPT Image 2.5 生图），或任何对话模型。

### 方式二：作为 Claude Skill 安装
把 [`deep-reading-xhs-cards/`](./deep-reading-xhs-cards) 这个文件夹作为 Skill 导入 Claude（Claude Code 用户可放进 `~/.claude/skills/`）。
之后只要说"把这篇文章拆成小红书卡片"，就会自动调用。

> Claude 本身不能直接生图。在 Claude 里使用时，阶段三会输出提示词，你再粘贴到 ChatGPT 或其他生图工具里出图。

## 使用小贴士
- **给原文，别只给书名。** 只给书名时，AI 只能凭印象拆，容易失真。
- **图里出现错字很正常。** 只重生那一张，并把那张卡的正文再压短；实在不行就只在图上留标题。
- **想换风格，直接说"换成 C"。** 只会重写风格部分，内容不动。
